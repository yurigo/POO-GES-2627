# Programación Orientada a Objetos — Grado en Ingeniería de la Salud

Este repositorio es el cuaderno de bitácora de la asignatura de Programación
Orientada a Objetos (POO). El material se incorporará progresivamente durante
el curso: cada sesión tendrá su propio directorio y el presente README actuará
como índice de navegación.
