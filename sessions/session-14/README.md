# Sesión 14 — Aparcamiento de vehículos

## Objetivo

Completar en clase el [ejercicio 3 de la sesión 13: Aparcamiento de
vehículos](../session-13/EXERCISES.md#3-aparcamiento-de-vehículos), aplicando la
herencia, el polimorfismo y las relaciones entre clases trabajadas en sesiones
anteriores.

## Trabajo en clase

Desarrolla el modelo UML y la implementación Java del ejercicio. Comprueba que
el diseño representa los distintos tipos de vehículo y sus tarifas, que cada
estancia corresponde a un único vehículo y que un vehículo puede tener varias
estancias. El aparcamiento debe permitir registrar estancias, calcular su coste
y obtener la recaudación del día, tal como indica el enunciado.

## Entrega

Entrega el ejercicio completo en el pozo de entrega el mismo día de esta sesión.
