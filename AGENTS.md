# Guía para agentes

## Propósito del repositorio

Este repositorio contiene material docente real utilizado durante el desarrollo
de una asignatura universitaria de Programación Orientada a Objetos en Java. No
es un libro completo escrito de antemano: es un cuaderno de bitácora que crece
sesión a sesión.

## Fuente de verdad

Para crear una sesión, la issue asignada es la fuente principal de verdad sobre
objetivos, contenidos, ejemplos utilizados en clase, ejercicios, tarea para
casa, nivel esperado y restricciones. El agente puede desarrollar y estructurar
estas ideas pedagógicamente, pero no debe cambiar el alcance docente indicado.

## Progresión pedagógica

Respeta estrictamente la progresión de contenidos del curso. No conviertas en
requisitos implícitos conceptos aún no introducidos solo porque produzcan código
Java más idiomático o elegante. Esto incluye, entre otros, constructores,
encapsulamiento, modificadores de visibilidad, `this`, relaciones, herencia,
polimorfismo, colecciones y excepciones.

La prioridad es la coherencia pedagógica, no producir el código Java más
avanzado posible.

## Conservación del histórico

Las sesiones anteriores representan lo que realmente se trabajó en clase. No
las modifiques retroactivamente al crear una sesión nueva, salvo que la issue lo
solicite expresamente. Las sesiones nuevas sí pueden enlazar o recordar
conceptos ya introducidos.

## Lenguaje y estilo

El material docente se escribe principalmente en castellano. Los nombres de
clases, métodos, variables y el código siguen las convenciones habituales de
Java.

El material debe ser claro, práctico, progresivo, apropiado para estudiantes de
primeros cursos de ingeniería, orientado a comprender conceptos mediante
ejemplos y suficientemente autocontenido para servir como repaso. Evita
convertir los README en capítulos excesivamente teóricos.
